# AXI-Lite 寄存器配置硬件方案

---

## 1. 设计概述

### 1.1 功能

CSR 模块负责：

- 接收 AXI-Lite 读写事务，配置 AWB 动态参数；
- 在帧边界把配置从影子寄存器同步到生效寄存器；
- 把 AWB 状态寄存器回读给软件；
- 处理 AXI 时钟域和像素时钟域之间的 CDC；

### 1.4 架构

```text
      AXI-Lite Slave (s_axi_aclk域)
              │ 
              ▼
   ┌───────────────────────┐
   │        写通道          │
   └───────────────────────┘
              │ 软件写
              ▼
   ┌───────────────────────┐
   │  影子寄存器 shadow_regs │  → 软件读
   └───────────────────────┘
              │ frame_start (pclk 域)
              ▼
   ┌───────────────────────┐
   │  生效寄存器 active_regs │  → 输出给 AWB（打一拍）
   └───────────────────────┘

       AWB 回写(pclk 域)
              │ pending_valid
              ▼
   ┌───────────────────────┐
   │  状态寄存器 status_regs │ 
   └───────────────────────┘
              │axi_araddr(s_axi_aclk域)
              ▼
   ┌───────────────────────┐
   │  输出寄存器 reg_data_out│ 
   └───────────────────────┘
              │ 软件只读
              ▼
   ┌───────────────────────┐
   │       读通道           │
   └───────────────────────┘          
```

#### 1.4.1 过程描述

- 写通道（aclk域）：通过AXI-Lite将动态参数写入影子寄存器
- 输出给AWB（pclk域）：1.帧起始输出生效寄存器 2.立即生效的立即输出
- AWB回写（pclk域）：AWB状态写入状态寄存器，等待读通道读取
- 读通道（aclk域）：通过AXI-Lite将状态读出

### 3.3 汇总

| 地址 | 寄存器名 | 类型 | 说明 |
| ---- | -------- | ---- | ---- |
| 0x00 | `REG_CTRL` | RW | 控制寄存器：软复位、边缘使能、Bayer 排布 |
| 0x01 | `REG_IMG_SIZE` | RW | 图像尺寸：宽度、高度 |
| 0x02 | `REG_RG_RANGE` | RW | R/G 比值窗口上下界 |
| 0x03 | `REG_BG_RANGE` | RW | B/G 比值窗口上下界 |
| 0x04 | `REG_MASK_CFG` | RW | 掩码配置：饱和阈值、顶部/普通权重 |
| 0x05 | `REG_CONF_SOG_0` | RW | SOG 置信度：强、中 |
| 0x06 | `REG_CONF_SOG_1` | RW | SOG 置信度：弱 |
| 0x07 | `REG_CONF_EDGE_0` | RW | Edge 置信度：强、中 |
| 0x08 | `REG_CONF_EDGE_1` | RW | Edge 置信度：弱 |
| 0x09~0x0F | Reserved | - | 保留 |
| 0x10 | `REG_STATUS_GAIN0` | RO | GR / GB 增益 |
| 0x11 | `REG_STATUS_GAIN1` | RO | GG 增益 |
| 0x12 | `REG_STATUS_FLAGS` | RO | 置信度、保持、场景变化、有效、软复位完成 |
